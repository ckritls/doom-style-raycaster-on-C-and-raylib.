# Doom-style Raycaster (C++17 + raylib)

Псевдо-3D стрелялка в духе Doom/Wolfenstein, написанная с нуля на C++17.
Рендер — классический raycaster (DDA) с текстурированными стенами и
спрайтами-противниками. Уровень генерируется процедурно (случайные комнаты и
коридоры), текстуры тоже генерируются процедурно — ассеты не нужны.
Это мой первый проект, а потому не бейте палками =P.

raylib скачивается автоматически из официального репозитория
<https://github.com/raysan5/raylib> (через `git clone`, а если git не
установлен — исходным архивом прямо с GitHub).

## Управление

| Клавиша                    | Действие                       |
| -------------------------- | ------------------------------ |
| `W` / `S` / `↑` / `↓`      | вперёд / назад                 |
| `A` / `D` / `←` / `→`      | поворот камеры                 |
| Мышь (движение по X)       | поворот камеры                 |
| `ЛКМ` / `Space` / `Ctrl`   | выстрел (SMG — удержание)      |
| `1` / `2` / `3`            | пистолет / дробовик / SMG      |
| Колесо мыши                | переключение оружия            |
| `R`                        | перезарядка                    |
| `Esc`                      | выход                          |
| `Enter` / `Space`          | новая область (после зачистки) |
| `R` / `Enter`              | новая область (после смерти)   |

В правом верхнем углу — миникарта (стены, враги, пикапы и игрок со стрелкой
направления). По карте разложены **аптечки** (лечат) и **броня** (гасит часть
урона). У пистолета бесконечный боезапас, у дробовика и SMG — конечный, с
перезарядкой. Выстрелы видны как трассеры. Все звуки (выстрелы, попадания,
урон, смерть врага, перезарядка, подбор предметов) генерируются процедурно —
ассетов не требуется.

Уровень генерируется заново при каждом запуске и после каждой зачистки:
случайные комнаты, соединённые коридорами, случайное число врагов (4–9) и
пикапов. Цель — уничтожить всех врагов; после этого создаётся новая область.

## Сборка (Windows, MinGW/MSYS2)

Требуется: CMake >= 3.16 и компилятор MinGW (например, `mingw-w64-ucrt-x86_64-gcc`).

```powershell
cmake -G "MinGW Makefiles" -S . -B build
cmake --build build
.\build\idk.exe
```

При желании можно собрать Release-версию:

```powershell
cmake -G "MinGW Makefiles" -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

## Сборка (Linux)

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/idk
```

## Структура

```
CMakeLists.txt        — сборка + автозагрузка raylib (FetchContent)
src/Config.h          — все игровые константы
src/Map.h/.cpp        — сетка уровня, коллизии, line-of-sight
src/Player.h/.cpp     — игрок (движение, поворот, стрельба)
src/Enemy.h/.cpp      — противник (A* вдоль стен, разлёт от соседей, атака)
src/Renderer.h/.cpp   — raycaster (стены + спрайты + z-buffer)
src/Textures.h/.cpp   — процедурные текстуры
src/Game.h/.cpp       — игровой цикл, процедурная генерация, HUD
src/main.cpp          — точка входа
src/sound.h/cpp       — музычка ^_^
```

## Как поменять версию raylib

В `CMakeLists.txt` измените переменную `RAYLIB_VERSION`.
